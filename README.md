# Mtoto Wa Nyota

Kenya & East Africa's Stillbirth Remembrance & Family Support Community.

## Deploy

This is a static HTML site. Deploy instantly to Vercel:

1. Push this folder to a GitHub repo
2. Import to Vercel at vercel.com/new
3. No build settings needed — Vercel detects it automatically

Or via Vercel CLI:
```bash
npm i -g vercel
vercel
```

## Structure

```
/
├── index.html      # Main site (single file)
├── vercel.json     # Vercel routing + headers config
└── package.json    # Project metadata
```
